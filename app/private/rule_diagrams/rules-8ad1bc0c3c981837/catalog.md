# Κατάλογος κανόνων Απολογιστικού — αναλυτική έκδοση (rules-v8)

Πηγές: `app/apologistic_rules.py`, `app/apologistic.py`, `docs/APOLOGISTIKO_LOGIC.md`.  
Τελευταία ενημέρωση: Σεπτέμβριος 2026.

**Αρχή:** Κάθε ημέρα παίρνει ακριβώς ένα `rule_id`. Άγνωστη περίπτωση → **Έλεγχος**.  
Το 5ήμερο/6ήμερο και οι κόφτες υπερεργασίας/υπερωρίας προέρχονται **μόνο από τη σύμβαση**.

| Badge | Όνομα | Σημασία |
|-------|--------|---------|
| **Σ** | Σύμφωνο (`ok`) | Δεν χρειάζεται απολογιστική μεταβολή· παραμένει το δηλωμένο. |
| **Μ** | Μεταβολή (`change`) | Συγκεκριμένη πρόταση ωραρίου ή/και υπερωρίας προς έγκριση/υποβολή. |
| **Ε** | Έλεγχος (`review`) | Ασάφεια ή ειδική περίπτωση· δεν εφαρμόζεται αυτόματα. |
| **Μ\*** | Μεταβολή από Έλεγχο | Αποδοχή γραμμής Ε ή ανταλλαγής· χειροκίνητο override. |

Για κάθε κανόνα παρακάτω: **Είσοδος → Συνθήκες → Αποτέλεσμα → Παράδειγμα**.

## 0. Κοινές έννοιες (πριν τους rule_id)

### Πεδίο

- Ανάλυση ανά επιχείρηση / εργαζόμενο / ημερολογιακή ημέρα / εβδομάδα **Δευτέρα–Κυριακή**.
- Είσοδοι: δηλωμένο ψηφιακό ωράριο + κάρτα + τρέχον snapshot σύμβασης.
- Προβολή `/ui/apologistic` μόνο από αποθηκευμένο snapshot (`karta_apologistic_run` / `_day`).
- Παραγωγή: scheduled Δευτέρα 03:00 (προηγούμενη εβδομάδα) ή backfill.
- Επανυπολογισμός το πολύ έως **χθες**.
- `generated_json` = κανόνας · `override_json` = χειροκίνητο · `effective_json` = UI.

### Καταστάσεις ημέρας

`ΕΡΓΑΣΙΑ` · `ΑΝΑΠΑΥΣΗ/ΡΕΠΟ` · `ΜΗ ΕΡΓΑΣΙΑ` · `ΤΗΛΕΡΓΑΣΙΑ` · `ΑΔΕΙΑ` · `ΑΡΓΙΑ` · χωρίς δηλωμένο.

### Διάλειμμα

- Αφαιρείται από την πραγματική διάρκεια **μόνο** αν `break_in_work=0` και θετική διάρκεια.
- Κενή ένδειξη → δεν αφαιρείται αυτόματα· απαιτεί επιβεβαίωση.
- Στην πρόταση ωραρίου **δεν** προστίθεται το διάλειμμα εκτός ως επέκταση του δηλωμένου διαστήματος.

### Ευελιξία

- Παράθυρο: δηλωμένη έναρξη … δηλωμένη έναρξη + `flex_arrival_minutes`.
- Μερική με flex: και τα δύο άκρα (είσοδος και έξοδος) πρέπει να είναι εντός παραθύρου για Σ.

### Ζώνες υπερεργασίας / υπερωρίας (μόνο σύμβαση)

| Καθεστώς | Βάση | Υπερεργασία | Υπερωρία | Max span (έλεγχος) |
|----------|------|-------------|----------|-------------------|
| Πλήρης 5ήμερο | έως 8:00 | 8:00–9:00 | μετά 9:00 (έως 4:00/ημ.) | >13ώ |
| Πλήρης 6ήμερο | έως 6:40 | 6:40–8:00 | μετά 8:00 (έως 4:00/ημ.) | >12ώ |
| Εκ περιτροπής | βάση σύμβασης 8:00/6:40 | καμία | μετά τη βάση (έως 4:00) | όπως σύμβαση |
| Μερική | τεκμαρτή / εβδομαδιαίο | καμία απολογιστική ΥΕ | χωρίς αυτόματη ΥΕ· στην ωρομέτρηση >8:00/6:40 → 120% | — |

Ημερομηνία υποβολής υπερωρίας = ημέρα **έναρξης** του υπερωριακού διαστήματος.  
Πρώτες 4ώ/ημέρα: 40%/60% από ετήσιο 150ώ · υπερβάλλον → 120%.  
WTOOvA πάνω από 150ώ έτους → δεύτερη επιβεβαίωση.

### Αντιστοίχιση χτυπημάτων (πριν τον κανόνα)

1. **Απλό, ένα ζεύγος:** πλησιέστερο στη δηλωμένη έναρξη/λήξη.
2. **Πολλαπλά μη σπαστά:** μέγιστο έγκυρο διάστημα έναρξης → μεταγενέστερης λήξης.
3. **Overnight:** ρητό `is_end_date_different` (`*`) ή θετικό διάστημα ≤ 13ώ (5ήμ.) / 12ώ (6ήμ.).
4. **Μεταφορά στην προηγούμενη:** ζεύγη νέας ημέρας εντός 13/12ώ (+διάλειμμα εκτός) από θεωρούμενη έναρξη χθες, πριν την κύρια βάρδια σήμερα.
5. **Δεύτερο άνοιγμα χωρίς κλείσιμο** μετά πλήρες ζεύγος: τεκμαρτό κλείσιμο στην ώρα ανοίγματος.
6. **Σπαστό δηλωμένο:** ένα χτύπημα ανά τμήμα· ορφανά → Ε.
7. **1 συνεχές δηλωμένο + 2 πλήρη ζεύγη, κενό ≥3ώ** → πιθανό σπαστό (Ε).
8. **Μόνο είσοδος ή μόνο έξοδος:** συμπλήρωση από δηλωμένο· **χωρίς** υπερωρία από τεκμαρτό. Σε ρεπό μισό χτύπημα → ίδια ώρα–ώρα, διάρκεια 0, Ε.
9. **Χωρίς κανένα χτύπημα** με δηλωμένη εργασία → Σ (κρατά δηλωμένο).

# Α. Ημερήσιοι κανόνες — κανονικό (μη σπαστό) ωράριο

Οι κανόνες αξιολογούνται με τη σειρά του `normal_schedule_decision`· το πρώτο ταίριασμα κερδίζει. Μετά μπορεί να επανεγγραφούν από ειδικούς μετα-κανόνες (ορφανά, max span, μη εργασία, κ.λπ.).

## `NO_PUNCH_OK`

| | |
|--|--|
| **Αποτέλεσμα** | **Σ** |
| **Είσοδος** | Δηλωμένη κατάσταση (εργασία / ρεπό / ΜΕ / άδεια κ.λπ.)· **κανένα** χτύπημα κάρτας. |
| **Συνθήκες** | `has_punch = false` και **όχι** μη προβλέψιμο σε ημέρα εργασίας. |
| **Έξοδος** | Πρόταση = δηλωμένο όπως είναι. Χωρίς τεκμαρτή εργασία, χωρίς υπερωρία. |
| **Παράδειγμα** | Δηλωμένο `09:00–17:00`, χωρίς κάρτα → **Σ**, πρόταση `09:00–17:00`. |

## `UNPREDICTABLE_NO_PUNCH`

| | |
|--|--|
| **Αποτέλεσμα** | **Μ** |

| **Έξοδος** | Πρόταση **`ΜΗ ΕΡΓΑΣΙΑ`**. |
| **Παράδειγμα** | Μη προβλέψιμο, δηλωμένο κάποιο ωράριο, χωρίς κάρτα → **Μ** `ΜΗ ΕΡΓΑΣΙΑ`. |

## `UNPREDICTABLE_PUNCH`

| | |
|--|--|
| **Αποτέλεσμα** | **Μ** |
| **Είσοδος** | Μη προβλέψιμο + πραγματικό χτύπημα με ασφαλή όρια. |
| **Συνθήκες** | `unpredictable` + έγκυρα `actual_start` / `actual_end`. |
| **Έξοδος** | Πρόταση από πραγματική έναρξη + διάρκεια = min(καθαρό χτύπημα, συμβατική βάση ή δηλωμένα λεπτά). |
| **Παράδειγμα** | 5ήμερο πλήρες, χτύπημα `08:00–18:00` (10ώ) → πρόταση έως 8:00: `08:00–16:00` (με διάλειμμα εντός). |

|--|--|

| | |
|--|--|

# ΣΤ. Μεταφορά ρεπό Κυριακής (όχι ξεχωριστό rule_id ημέρας)

Ρύθμιση καταστήματος `sunday_rest_transfer_enabled` + συμβατικό 5ήμερο + Κυριακή (ή αργία) τουλάχιστον 6η ημέρα με κάρτα + καθαρή διάρκεια **&gt; 5:00** → εκκρεμότητα οφειλόμενου ρεπό στην επόμενη εβδομάδα (`pending` / `satisfied` / `cancelled`). Εμφάνιση «Οφείλεται ρεπό» στο UI της επόμενης εβδομάδας. Δεν αλλάζει από μόνο του το `rule_id` της Κυριακής.

# Ζ. Ωρομέτρηση (μετά το απολογιστικό)

Τρέχει **μόνο** όταν όλα είναι Σ/Μ, **χωρίς καμία Ε**.

- Καθαρή βάση με διάλειμμα· ζώνες ημέρα / νύχτα 25% (`22:00–06:00`) / Κυρ-Αργία 75% / συνδυασμός.
- Πλήρης ανισομερής: επέκταση έως 40:00 εβδομαδιαίως· μετά ΥΕ/υπερωρία.
- Μερική 12%: θετική εβδομαδιαία διαφορά στα ημερήσια υπερβάλλοντα Δευ→Κυρ· ουρά πάνω από 8:00/6:40 → 120%.
- 6η ημέρα πλήρους: με 6 αναγνωρισμένες ημέρες· προτεραιότητα σε δηλωμένο ρεπό/ΜΕ· fallback Κυρ→Δευ.
- Άδεια εξαιρείται από ωρομέτρηση / σύνολα / υπερωρίες.

Πλήρης περιγραφή: `docs/APOLOGISTIKO_LOGIC.md` (ενότητα Ωρομέτρηση).
